# Order mixed placeholder parameters

A resource key may combine named and indexed placeholders to preserve flexibility while supporting .NET composite formatting. Its generated signature places distinct named arguments first, in order of first appearance in the reference translation, followed by indexed arguments in numeric order. Indexed identities are independent of named arguments; gaps are allowed, and only used arguments become parameters. For `{name} {2} {0}`, these parameters are `name`, `arg0`, and `arg2`. Every translation must use exactly those argument identities: adding index `1` or omitting a reference argument is a compilation error. Translations cannot change the public parameter order by reordering placeholders. Documentation will recommend using a single placeholder style per resource key, but mixed styles remain supported.
